# Industry Proof Run — selling beats

Compiled from current industry HTML under [`../../demo-decks/`](../../demo-decks/). Figures on slides are **illustrative**.

Shared structure (what changes per vertical: prescriptions, data sources, optimisation targets, hero photo).

## Shared arc

| Scene | Job (headline pattern) |
|-------|-------------------------|
| Title | Act on [vertical] opportunities before the window closes · ₹-scored prescriptions |
| Hook | You already see the plant. Who should act, and on what? |
| Savings map | Where we look first in [vertical] |
| What Stamped does | From plant data to operator decisions |
| Prescription | Every action has a bill line and an owner |
| Floor | On the supervisor's phone (routed; not dump-all) |
| Verify | Verified with evidence · telemetry held; bill can confirm later |
| Tech / audit / boundaries | Stack · finance-checkable trail · humans approve · no autonomous plant control |
| Offer | First prescriptions in about two weeks · no rip-and-replace |
