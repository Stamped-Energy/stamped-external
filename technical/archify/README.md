# Stamped system archify

Start at [index.html](index.html). Ten SYS diagrams under `system/`.

Stamped helps plant teams choose, assign, and verify the next operating action across energy, cost, time/throughput, continuity/flow, and short-horizon exceptions. Plant data enters through L1 connectors, is stored in the L2 universal repository, and becomes Findings in L3. L4 recommends actions and drafts card proposals; L5 owns live workflow, M&V, and the ledger; L6 is the control room. Layers communicate only through versioned contracts in stamped-external (ADR-030). What is BUILT means code on main with tests—not production deployment. No integration is live at any customer plant; verified savings to date are ₹0. Use the reader path below, then drill into per-repo diagrams via the layer table.
