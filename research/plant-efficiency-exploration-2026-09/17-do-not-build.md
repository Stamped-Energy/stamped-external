# What this architecture will not build

**Date:** 2026-09-24
**Status:** Boundary for the coarse pass and for the layer repos that follow it.
**Authority:** [`09-stamped-founder-vision.md`](09-stamped-founder-vision.md) §12 and §8. The L4 **agentic system** and an open L3 detection ceiling in [`14-coarse-architecture.md`](14-coarse-architecture.md) / [`technical/STAMPED_ARCHITECTURE.md`](../../technical/STAMPED_ARCHITECTURE.md) are in scope. The list below is not.

## In scope, so it is not on this list

L4 as a proper agentic system (planning, tools, memory, evaluation — not memory alone). Hindsight as the memory subsystem. A cross-section check before one card. Specialist passes that reconcile into that one card. Decision seams a later decision model may fill. L3 detection / methods / eval uplift above today’s floor. A certified autonomy catalog that defaults to off. A richer L6 card, including constraint editing and Ask. Studying state-of-the-art agentic systems to raise the bar.

## Failure modes copied from peers

**Semantic model before a decision.** Standardizing a line-wide production model before any owned card exists turns L2 into a mapping program and L6 into a dashboard. A mapping ships when a live family's detector or verification plan reads it. See [`11-competitive-set.md`](11-competitive-set.md) on Sight Machine.

**The graph becomes the product.** A broad industrial graph, with actions on the graph, makes every ontology change a contract change and reopens ungated side effects. Stamped does not own the plant's data model.

**Optimization becomes a setpoint.** Ranking a modeled benefit above a known constraint, or writing a setpoint because a model is confident, breaks the hard stops even if a person could have clicked. Equipment actions stay human-only.

## Named exclusions

- Ingest every plant system, or stand up a plant-wide ontology, knowledge graph, or unified namespace as a prerequisite.
- An MCP server as a product surface.
- Silent control, including OPC UA write pipelines and setpoint push.
- Sensing pods, and any product claim that Stamped runs the plant.
- A second chatbot memory inside the plant bank, or a transcript retained as operating knowledge.
- Jev, or any decision model, wired in during this notes pass. The seams are reserved. They are not called.
- ML effect estimators that invent a counterfactual price.
- A catalog of plant controls. A new autonomy class is a proposal that stays off until Stamped certifies the earned-run test.
- Five queues, or one headline that adds energy and machine-minutes.
- Editing Prescription 1.0.0 in place.
- Layer-repo implementation in the same pass as these notes. Sequence: [`18-propagation.md`](18-propagation.md).
